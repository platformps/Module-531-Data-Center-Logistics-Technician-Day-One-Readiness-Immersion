GLAB 531.3.1 — DCIM Asset Records

Scenario set C~65 minincludes bench work
How to work this lab10 steps · read this first

What you hand in: One PDF showing four DCIM tasks done in the training instance — find, create, move, report — and three physical lookups plus one physical move at the bench.

  1. DCIM training instance. Use the search box above the asset table. It filters the table live across tag, serial, model and location as you type.Clear the box to see all rows again.
  2. Task 1 — find three assets. Search for the tag, the serial and the location on the task card, and after each search press the matching Capture button (tag lookup / serial lookup / location lookup).Each capture line changes from not captured yet to the row it found. Three captures.
  3. Task 2 — create the missing record. Type every field exactly as the task card gives it (tag, serial, model, category, location, status, custody) and press Create record.The new row appears in the table. A typo in the tag or serial is a wrong record, not a near miss — check before you press.
  4. Task 3 — apply the move. Enter the new location, status and custody from the task card and press Apply update.The row for that asset changes in the table.
  5. Task 4 — the report. Press Run report.A report of everything at the task-card location appears — it should include the asset you just moved.
  6. Press Save simulator record (the numbered button under the last simulator panel).A Simulator record table appears under the button. A green line means it is complete; a red line names exactly which panel or field is still missing — fix that item, then press Save again.
  7. Bench panel — Part 4. For each of three lookups: click into Asset tag on the item and scan any tagged kit item in the room, then choose True/False for whether it is where the register says. For the physical move: carry the PSU or fan module from its shelf bin to the STAGE-1 cart, scan its FRU tag at the cart, and choose the new location.Three lookups and one move.
  8. Press Save bench record.A Bench record table appears. A red line names anything missing; a green line reads Bench record complete.
  9. Scroll to Lab submission — questions and responses. Type your name, cohort and date, then answer every question.Each question carries its handout step number (for example Step 3). The progress bar at the top counts answered questions (for example Questions 5/8) — it must reach the full count. Where a question asks for an image, use Choose File to attach a photo or screenshot.
  10. Press Build submission PDF. In the print dialog choose Save as PDF and name the file Lastname_Firstname_531.x.y (the tool suggests it).If anything is still missing, the tool lists the gaps instead of printing — fix them and press again. Upload the one PDF to the matching Canvas assignment. That single file is your submission.
You are finished when:
  • The Simulator record and the Bench record both show a green complete line.
  • The progress bar shows every question answered (for example Questions 8/8).
  • You have saved the PDF and uploaded it to Canvas.
Good to know
  • Your typed answers are saved in this browser as you type, so a refresh does not lose them.
  • Use Preview without printing to check the PDF before you build it.
  • If Print label opens nothing, allow pop-ups for this file in the browser and press it again.
  • Stuck for more than two minutes? Ask your instructor — do not guess at a scan field.

How this tool works
