How to use this page

Open only the set your instructor assigned (A, B, or C). The letter is just a scenario label; every set has the same questions and the same rubric. Labs shown in green have a single scenario.

Inside each tool: work the panels, answer every numbered question, press Build submission PDF, save with your browser's Save as PDF, and upload that one PDF to Canvas. Your work autosaves in this browser as you type.
